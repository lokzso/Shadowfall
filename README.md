# SHADOWFALL: REBORN

Браузерная тёмно-фэнтезийная RPG/MOBA, которая запускается на ПК и iPhone прямо через браузер.

## Текущая версия

Проект теперь собран максимально просто:

- вся игра находится в одном файле `index.html`;
- отдельные папки `assets` больше не нужны;
- отдельные `game.js`, `style.css` и `manifest.json` больше не нужны;
- графика, интерфейс и код встроены прямо внутрь `index.html`;
- игру удобно обновлять и загружать на GitHub даже с iPhone.

## Управление

### ПК

- `WASD` или стрелки — движение;
- `Q / W / E / R` — способности;
- `Пробел` — обычная атака;
- `F` — разговор / взаимодействие;
- клик мышью — движение к выбранной точке.

### iPhone

- левый виртуальный стик — движение;
- кнопки `Q / W / E / R` — способности;
- кнопка меча — обычная атака;
- кнопка диалога — взаимодействие с NPC.

Для удобства рекомендуется играть в горизонтальной ориентации.

## Как должен выглядеть репозиторий

В корне репозитория достаточно:

```text
index.html
README.md
```

Старые файлы можно удалить:

```text
game.js
style.css
manifest.json
assets/
```

Текущая версия игры их не использует.

## Как обновить игру с iPhone

1. Скачай новый `index.html`.
2. Открой GitHub через Safari.
3. Зайди в репозиторий `Shadowfall`.
4. Удали старый `index.html`.
5. Нажми `Add file` → `Upload files`.
6. Выбери новый `index.html` из приложения «Файлы».
7. Нажми `Commit changes`.
8. Подожди примерно 1–2 минуты.
9. Открой:

```text
https://lokzso.github.io/Shadowfall/
```

Если показывается старая версия, обнови страницу или закрой вкладку Safari и открой сайт снова.

## Сохранение

Прогресс сохраняется локально в браузере через `localStorage`.

Это значит:

- после перезагрузки страницы прогресс остаётся;
- сохранение действует на том же устройстве и в том же браузере;
- если очистить данные Safari или нажать сброс сохранения в настройках игры, прогресс удалится;
- сохранения пока не синхронизируются между iPhone и ПК.

## Важно

Игра использует оригинальных персонажей и собственный мир.

Она вдохновлена классическими RPG, MOBA и RTS по структуре управления и игровым системам, но не копирует героев Dota или Warcraft.
