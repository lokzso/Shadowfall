# SHADOWFALL: REBORN 3D

Полностью переделанная браузерная версия. Теперь персонажи — настоящие 3D-модели с ригом и анимациями, а не геометрические заглушки.

## Что изменилось
- полноценный WebGL/Three.js 3D-мир;
- настоящие анимированные 3D-персонажи;
- 12 героев на базе 5 разных 3D-классов/моделей;
- idle / run / attack / cast / death анимации;
- анимированные враги-скелеты;
- изометрическая камера;
- свет, туман, тени, факелы, река, мост, крепость, башни, лес;
- волны союзных и вражеских юнитов;
- Q/W/E/R, обычная атака и эффекты;
- NPC, диалоги с вариантами ответа;
- сюжетные задания, магазин, инвентарь, прокачка;
- управление на ПК и iPhone;
- сохранение через localStorage.

## Загрузка с iPhone
Никаких папок не нужно.

В репозитории достаточно:
- index.html
- README.md

Просто замени старый index.html новым.

## Важно
3D-модели и Three.js загружаются через CDN при запуске игры, поэтому нужен интернет.
