# Shadowfall: Warborn — iPhone FIX v1.1

Эта версия специально переделана после чёрного экрана на iPhone.

Главное изменение: игра больше НЕ зависит от Phaser/CDN/WebGL. Рендер идёт встроенным HTML5 Canvas 2D, поэтому для запуска не требуется загружать игровой движок с внешнего сайта.

## Как обновить GitHub с iPhone
В репозитории удали/замени старые:
- index.html
- style.css
- game.js
- manifest.json

Загрузи четыре одноимённых файла из этой папки в КОРЕНЬ репозитория. README.md можно тоже заменить.

После загрузки:
1. Подожди 1–2 минуты, пока GitHub Pages обновится.
2. В Safari открой сайт.
3. Если видна старая версия, обнови страницу. При необходимости закрой вкладку и открой снова.

## Что должно быть при запуске
Сначала появляется экран SHADOWFALL WARBORN с полосой запуска, затем выбор из трёх героев. Полностью чёрного экрана быть не должно. Если JavaScript всё же упадёт, текст ошибки появится прямо на экране вместо пустой страницы.

## Управление
ПК: WASD/стрелки, клик для движения, Q/W/E/R, F, I, B, T.
iPhone: левый стик, Q/W/E/R, F/I/B.

## Системы
Карта, 3 героя, способности, мобы, боссы, квест, NPC, торговец, инвентарь, экипировка, уровни, XP, золото, таланты, башни/строительство, крипы на линиях и локальное автосохранение.
