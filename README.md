# Shadowfall: Warborn — FULL browser build

Это расширенная единая сборка проекта, рассчитанная на ПК и iPhone.

## Системы в сборке
- 3 героя: Воин, Маг, Следопыт
- разные параметры и наборы Q/W/E/R
- большая карта: крепость, лес, река, три направления/дороги
- обычные враги + боссы
- союзные и вражеские крипы
- башни
- RPG: уровни, XP, золото, характеристики
- талант-поинты и улучшение героя
- инвентарь
- экипировка
- расходники/лут
- NPC
- торговец
- цепочка квестов
- строительство своей башни
- сохранение в браузере
- ПК: WASD/стрелки, ПКМ, QWER, F, I, T, B
- iPhone: виртуальный стик, QWER, F/I/B
- PWA manifest

## Загрузка с iPhone
1. Распакуй ZIP через приложение «Файлы».
2. Создай репозиторий GitHub.
3. В Safari открой репозиторий → Add file → Upload files.
4. Загрузи СОДЕРЖИМОЕ папки Shadowfall_RPG_FULL в корень репозитория.
5. GitHub → Settings → Pages → Deploy from a branch → main → /(root) → Save.
6. Открой появившийся адрес Pages.
7. Safari → Поделиться → На экран «Домой».

index.html обязательно должен лежать в корне.

## Важно
Это полностью играбельный браузерный vertical slice со всеми основными системами в одном проекте. Для настоящей коммерческой MMO/MOBA серверный мультиплеер, аккаунты, матчмейкинг и постоянная серверная БД требуют отдельного backend/server deployment и не могут быть честно заменены локальным HTML.
